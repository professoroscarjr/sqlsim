Legenda de Tipos em SQL

MariaDB / MySQL
Tipos Numéricos
INT ou INTEGER

Números inteiros positivos ou negativos sem casas decimais (Ex: 10, -50).

BIGINT / SMALLINT

Variações para inteiros extremamente grandes ou pequenos.

DECIMAL(p,s) / NUMERIC

Números exatos com casas decimais. Ex: DECIMAL(10,2) para moedas (Ex: 1250.50).

FLOAT / DOUBLE

Números decimais de ponto flutuante de precisão simples ou dupla.

Tipos de Texto
VARCHAR(n)

Texto de tamanho **variável** de até n caracteres. Ex: VARCHAR(100) para nomes.

CHAR(n)

Texto de tamanho **fixo**. Preenche espaços em branco se for menor. Ex: CHAR(2) para sigla de UF ('SP', 'RJ').

TEXT

Blocos longos de texto (descrições, artigos) sem limite fixo predefinido.

Data e Hora
DATE

Armazena apenas data no formato YYYY-MM-DD. Ex: '2026-09-02'.

TIME

Armazena horário no formato HH:MM:SS.

DATETIME / TIMESTAMP

Combina data e hora: YYYY-MM-DD HH:MM:SS.

Modificadores e Regras
PRIMARY KEY

Identificador único exclusivo de um registro na tabela.

AUTO_INCREMENT

Gera valores numéricos sequenciais automaticamente a cada novo registro.

NOT NULL

Impede que o campo fique sem preenchimento (vazio).

BOOLEAN / BOOL

Valores lógicos Verdadeiro/Falso (Internamente mapeado como 1 ou 0).
